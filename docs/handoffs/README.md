# 交接记录

未完成任务也能交接。复制 [handoff 模板](../templates/handoff.md)，保存为 `docs/handoffs/<task-id>.md`，与对应代码 PR 一起更新。每个任务保留一份当前状态，不要求每次对话生成一个文件。

下一位接手前先看任务卡、当前分支/commit、最后成功命令和待完成验收。已确认事实应能通过仓内证据或可共享 artifact 核对；推测明确标为待验证。

离开一个长任务时写清楚运行作业、当前错误及下一位的 1–3 个动作。完成后记录验证结果和剩余限制。普通文字小修可在 PR 中说明不适用，不必生成空交接文件。

不要提交内部评审、未公开代码、密钥、机器绝对路径或整段 AI 聊天。当前样例与测试是 CPU 契约证据，不能写成模型性能或仿真效果已验证。
