# Synthetic 轨迹样例

这里的两条轨迹都是按解析公式构造的 **synthetic 数据**，用于检查具身轨迹小工具的输入、速度与平滑度指标。它们不是机器人记录、模型输出，也不是量化或异步方案的实验结果；文件名不代表任何方法优劣。

| 文件 | 内容 |
| --- | --- |
| [smooth.csv](smooth.csv) | 平滑的三维参数曲线 |
| [perturbed.csv](perturbed.csv) | 同一曲线叠加毫米量级高频扰动 |

CSV 列固定为 `t,x,y,z`。`t` 单位为秒，`x,y,z` 单位为米，位于同一任意合成笛卡尔坐标系。每个文件包含表头和 101 个采样点，共 102 行；采样率为 50 Hz，时间覆盖 0 至 2 秒，包含两端点。没有缺失值、随机采样、过滤或重采样。

## 确切生成公式

令整数 `i = 0, 1, ..., 100`，所有三角函数使用弧度：

```text
t_i = i / 50
u_i = i / 100 = t_i / 2
s_i = 10 u_i^3 - 15 u_i^4 + 6 u_i^5

x_i = 0.40 s_i
y_i = 0.06 sin(π s_i)
z_i = 0.20 + 0.04 sin(2π s_i)
```

`smooth.csv` 使用上述坐标。`s(u)` 是常用的 minimum-jerk 标量时间律；经过非线性曲线映射后，这里不宣称整条三维曲线是笛卡尔空间的全局最小 jerk 解。

`perturbed.csv` 使用以下确定性扰动：

```text
w_i = sin²(π u_i)

x'_i = x_i + 0.0010 w_i sin(2π · 10 · t_i)
y'_i = y_i + 0.0008 w_i sin(2π · 12 · t_i)
z'_i = z_i + 0.0006 w_i sin(2π · 14 · t_i)
```

三个坐标的扰动幅度上界依次为 1.0、0.8、0.6 mm，载波频率依次为 10、12、14 Hz，均低于 25 Hz 的 Nyquist 频率。欧氏位移扰动上界为 `sqrt(1.0² + 0.8² + 0.6²) ≈ 1.414214 mm`，不是每个采样点都会达到这个上界。包络在两端为零，两条轨迹具有相同的起终点。

生成时用上述 `i/50`、`i/100` 计算，采用 Python 标准库 `math.sin` 的双精度结果；时间写为小数点后 2 位，坐标写为小数点后 12 位，UTF-8 编码和 LF 换行。不同数学库最后几位可能有差异，可按数值容差核对。生成过程不需要随机 seed。

## 指标解释

区间速度由相邻位置差除以相邻时间差得到，属于整个采样区间，不能直接当成端点瞬时速度。非均匀时间数据也可计算该速度，但不应套用等间隔的 paper jerk 公式。

若工具计算等间隔轨迹的 jerk，需记录差分 stencil、有效样本位置和边界处理。MSJ 应先计算每个有效时刻的 `jx² + jy² + jz²`，再按声明的规则对时间求平均，单位为 `m²/s⁶`；不能将时间和坐标维一起平均，也不能先求 jerk 均值再平方。这里仅提供轨迹，不预填或冒充论文指标结果。
